<h1>Hangman Game</h1>
<p>The project <strong>"Hangman Game"</strong> is a simple game developed in Java that consists of guessing a random word selected by the program. The player must try to guess the word, letter by letter, before the attempts run out and the gallows is completely assembled. The project was completely object-oriented, following good Java programming practices.</p>
<h2>Installation instructions:</h2>
<p>To install and run the game, follow the steps below:</p>
<ol>
  <li>Clone the repository to your local machine using the following command:
    <br>
    <code>git clone https://github.com/hiag0liveira/Jogo-da-Forca.git</code>
  </li>
  <li>Navigate to the project directory using the following command:
    <br>
    <code>cd Hangman</code>
  </li>
  <li>Compile the project using the following command:
    <br>
    <code>javac JogoDaForca.java</code>
    <ul>
      <li>Note that you must have the Java Development Kit (JDK) installed on your machine to run this command.</li>
    </ul>
  </li>
  <li>Run the main game file with the following command:
    <br>
    <code>java JogoDaForca</code>
  </li>
</ol>
<h2>How to play:</h2>
<ol>
  <li>When you start the game, you will see the word to be guessed represented by dashes (_).</li>
  <li>You must guess one letter at a time by typing it and pressing Enter.</li>
  <li>If the letter is in the word, it will be revealed in the dashes (_).</li>
  <li>If the letter is not in the word, a part of the gallows will be drawn.</li>
  <li>You have 6 attempts to guess the word before the gallows is completely assembled.</li>
  <li>If you guess the word before the gallows are set up, you win. Otherwise, you lose.</li>
</ol>
